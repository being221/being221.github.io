图表库选哪个？

两个主流选择，风格和能力不同

A

Recharts（推荐）

React 生态最流行的图表库，声明式 API，组件化思维。饼图、折线图、柱状图开箱即用。

🥧 PieChart
📈 LineChart
<PieChart>
  <Pie data={data} />
</PieChart>

优点

  • React 原生，声明式 API 很好懂
  • 社区最大，文档丰富
  • 定制灵活，支持动画

缺点

  • 需要自己写 tooltip 和响应式
  • 默认样式偏基础
B

shadcn/ui Charts

基于 Recharts 封装，提供预置好的配色、tooltip、响应式。开箱即用的精美图表，但需要先配好 shadcn/ui 体系。

npx shadcn@latest add chart
预置：
统一配色 Tooltip Legend 响应式

优点

  • 默认就很精美，不用自己调样式
  • 暗色主题自动适配
  • 和 shadcn/ui 组件体系打通

缺点

  • 需要先安装 shadcn/ui 全家桶
  • 定制自由度稍低
  • 学到的 Recharts 知识隔了一层
