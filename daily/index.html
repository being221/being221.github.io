💭 每日一题 · 使用说明

📅 每日机制

每天自动从题库中随机抽一道开放式问题。所有人都看到同一道题。次日零点自动换新题。

✍️ 回答

在下方的文本框写回答，可留署名也可匿名。提交后你的答案会出现在该题的回答列表中。

❤️ 点赞

给任何回答点赞（每人每条限一次）。点赞多的回答会自动排在上面。

📅 历史

点击右上角「历史」可以按日期翻阅过去的问题和所有回答。

🔐 隐私

回答者的身份通过设备 ID 匿名标识（不显示真实身份）。只有管理员可以删除不当回答。

👑 管理员

在主页 F12 Console 输入 localStorage.setItem("sb_admin","true")，刷新后可删除回答和人工换题。
