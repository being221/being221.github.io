# 墨脉 Ink Vein — 游戏设计文档

> 创建日期：2026-06-18  
> 状态：设计完成  
> 引擎：Godot 4  
> 目标平台：Steam（首期 Windows）

## 一、产品定位

### 1.1 一句话简介

地底墨脉觉醒，化墨为刃，斩杀腐灵，在割草与爆发之间循环的暗黑水墨幸存者。

### 1.2 核心体验承诺

每一局 25 分钟是一条**涨潮-落潮的波浪线**：

```
小怪割草 → 墨能积攒 → 涨墨爆发(全屏清场) → 精英/Boss挑战
  ↑                                                      ↓
  └─────── 新一波更强敌人 ← 爆发后短暂虚弱期 ←──────────┘
```

循环周期约 3-5 分钟，每轮敌人更强、Build 更成型，直至最终 Boss。

### 1.3 目标受众

- **核心**：类幸存者玩家（Steam 标签：Bullet Heaven / Survivors-like）
- **次级**：中国风/东方美学爱好者
- **钩子**：手感和视觉追求极致，截图即可吸引愿望单

### 1.4 Steam 定位

- 定价：15-25 元，首发折扣 10-15%
- 标签：动作类Rogue、子弹天堂、水墨、黑暗奇幻、单人
- 对标：《吸血鬼幸存者》《Brotato》《20 Minutes Till Dawn》

## 二、核心玩法

### 2.1 单局结构（~25分钟）

| 阶段 | 时间 | 内容 |
|------|------|------|
| 开场 | 0-3min | 少量慢速小怪，快速点上第一批基础属性 |
| 暖机 | 3-10min | 敌人密度上升，经历 1-2 次涨墨爆发，第一个精英 |
| 高压 | 10-20min | 全种类敌人混编，爆发节奏决定生死，双精英同时在场 |
| 终局 | 20-25min | 清场 → Boss 1v1，击破/被淹没 |

### 2.2 涨墨系统 (Ink Surge)

四环反馈链：**每次出手爽 → 连锁反应爆屏 → 逆袭质变 → 收割收菜**

```
击杀敌人 ──→ 涨墨条（3段）──→ 满段爆发
  ↑              │              ┌──────────┐
  │              │              │ 全屏清场    │
  │              │              │ 无敌帧      │
  │              │              │ 墨花四溅    │
  │              ↓              └──────────┘
  └── 爆发后额外墨能碎片 + 经验倍率短暂提升
```

- 涨墨条分 3 段，满 1 段可小型爆发，满 3 段全屏大招
- 可手动也可自动释放（设置选择）
- 爆发后 3 秒虚弱：移速略降，无法积墨

**释放前预兆（压抑-释放曲线）：**

```
涨墨 1/3 → 武器拖尾渗出墨滴
涨墨 2/3 → 屏幕边缘墨染暗角 + 低频嗡嗡渐强
涨墨 3/3 → 画面微抖 + 敌人速度略降 + 时间凝滞感
              ↓
       手动释放 / 3秒后自动
              ↓
       全屏墨爆 + 短暂全黑 + 唯一的光是敌人碎成墨花
       + 安静0.5秒 → 音效炸裂
```

### 2.3 连击 & 墨沸系统

**命中停帧 (Hit Stop)**：命中瞬间暂停 2-4 帧（`Engine.time_scale`）。

**墨痕残影状态：**

| 连击数 | 状态 | 效果 |
|--------|------|------|
| 0-9 | 正常 | 基础墨痕拖尾 0.3s |
| 10-29 | 燃墨 | 拖尾变亮变粗 |
| 30+ | 墨沸 | 全屏墨痕不散 + 音效渐强 + 屏幕边缘墨染暗角 |

断连 1.5 秒后逐级回落。

### 2.4 墨骸残留系统

敌人死亡留下墨渍/墨骸（持续 15 秒）：
- 踩上墨骸：减速周围敌人（被动控场）
- 涨墨爆发：引爆所有墨骸造成连锁伤害
- 特定 Build 可消耗墨骸（回血/加攻）

### 2.5 虹吸收割

涨墨爆发后 2 秒自动虹吸——所有墨能/经验碎片飞向玩家。碎片越多飞行音效越密集（雨滴→暴雨→瀑布），吸完显示"墨脉共鸣·X段"。

### 2.6 逆袭临界点

- 血量低于 30%：涨墨速度 +50%
- 首次 3 段涨墨：画面定格 + 文字"墨脉觉醒" + 音乐切高潮

## 三、Build 系统

### 3.1 三大分支

| 分支 | 定位 | 代表卡牌 |
|------|------|----------|
| **沥墨** | 攻击/快节奏 | 墨刃加速、墨刃分裂、残影追斩、沥墨成雨、千墨斩 |
| **凝墨** | 重击 | 凝墨一击、墨核凝聚、墨脉共振、蓄墨爆发、碎墨震、墨崩 |
| **御墨** | 节奏/爆发 | 墨能涌动、墨池扩大、墨潮预兆、墨能回收、双潮迭起、墨脉永动 |

### 3.2 通用卡牌

墨步、墨铠、墨吸、墨愈、墨涡、墨遁

### 3.3 共鸣系统

每张卡含潜关键字。集齐同关键字达到数量触发共鸣：

| 共鸣 | 条件 | 效果 |
|------|------|------|
| 连刃共鸣 | 3张"分裂/溅射/额外攻击" | 所有额外攻击有概率再触发一次 |
| 碎墨共鸣 | 3张"爆炸/范围/溅射" | 击杀爆炸在原地留下小墨池 |
| 潮汐共鸣 | 3张"涨墨/爆发/回收" | 爆发不再清空涨墨条，保留1段 |
| 残影共鸣 | 3张"残影/拖尾/墨痕" | 残影变实体，存在期间自动攻击 |
| 绝境共鸣 | 3张"低血量/减伤/抵消" | 低于30%血时所有伤害翻倍 |

### 3.4 禁忌卡

高回报带代价：

| 卡牌 | 效果 | 代价 |
|------|------|------|
| 墨癫 | 攻速+40%，暴击+20% | 无法控制攻击方向（自动索敌） |
| 墨祭 | 爆发伤害翻倍 | 爆发时扣除15%当前生命 |
| 墨朽 | 敌人移速-25% | 自身攻速-15% |
| 墨狂 | 击杀回满墨能条 | 受伤+30% |
| 墨蚀 | 每秒自动积攒墨能 | 每秒扣1%生命（不致死） |
| 墨寂 | 所有伤害+50% | 无法获得涨墨爆发 |

### 3.5 两层质变

**第一层（5分钟/精英触发，6选3列出）：**
- 墨脉·沥：武器→三连击形态
- 墨脉·凝：武器→单发重击形态
- 墨脉·御：涨墨条1段化，频率翻倍
- 墨脉·破：爆发伤害可暴击
- 墨脉·噬：击杀精英吸收其能力
- 墨脉·渊：解锁第4条涨墨段，满4段触发"墨渊降临"

**第二层（仅Boss前触发一次，终极选择）：**
- 千墨归一：多重攻击合并为单次×总伤害80%（凝墨流）
- 墨河无尽：连击不断则攻速无限叠加（沥墨流）
- 潮汐之主：爆发时额外召唤3波墨潮（御墨流）
- 墨蚀万象：持续扣血但所有伤害改为百分比真伤（赌命流）

### 3.6 升级选择层

- 每级 3 选 1 卡牌
- **重掷**：每局免费 3 次，消耗墨晶可额外
- **封印**：本局不再出现某张卡（限 1 次）
- **预览**：稀有卡出现前一级预告闪烁

### 3.7 墨变（视觉 Build 反馈）

| Build 倾向 | 外观变化 |
|------------|----------|
| 沥墨 > 凝墨 | 墨刃变细变亮，拖尾变长，角色多残影 |
| 凝墨 > 沥墨 | 墨刃变宽厚重，拖尾短粗，步伐变沉 |
| 御墨为主 | 胸口墨核发亮，墨尘环绕 |
| 触发过绝境 | 墨痕从黑色→赤墨色（永久局内印记） |
| 集齐任意共鸣 | 头顶浮现对应符文徽记 |

### 3.8 局外永久成长：墨脉图谱

- 放射状技能树网络，从中心向外解锁
- 每局结束获得墨晶，点亮相邻节点解锁对应卡牌入牌池
- 隐藏节点需满足条件显现
- 图鉴集齐所有敌人 → 解锁隐藏Boss「墨脉真灵」
- **不设计纯数值永久成长**

## 四、敌人系统

### 4.1 设计原则

1. 每个敌人有唯一行为特征，看剪影就知道是谁
2. 敌人之间互相配合
3. 攻击有前摇提示（不是躲弹幕，是选择硬刚还是走位）

### 4.2 小怪（墨蚀灵体）

| 敌人 | 外形 | 行为 | 识别音 |
|------|------|------|--------|
| 墨浮 | 拳头大墨团，漂浮 | 慢慢飘，碰触伤害，死后分裂2个更小的 | 咕噜声 |
| 墨蠕 | 地面墨水爬行，细长 | 从脚下墨迹窜出，直线冲刺，0.5s前摇地面墨圈提示 | 沙沙声/破土"唰！" |
| 墨爆 | 膨胀墨球，内部泛光 | 追2秒→膨胀→爆炸，半径范围+留墨迹减速地板 | 低频嗡/闷爆 |
| 墨缚 | 细墨丝，鞭状 | 不攻击，远程投墨丝减速玩家 | 细丝风声 |
| 墨蛹 | 小型墨茧，不动 | 不攻击，15秒孵化3只墨蠕+1只墨爆，逼主动拆 | 心跳般咚咚/孵化撕裂 |
| 墨蛭 | 吸附型小墨块 | 跳身上持续吸墨能（涨墨条倒退），需跑3秒甩掉 | 高频吱吱/吸附"啪" |
| 墨镜 | 扁平圆盘，表面反光 | 不攻击，反射投掷类技能，近战无威胁 | 静默 |
| 墨影(稀有) | 玩家剪影扭曲版 | 随机出现，模仿玩家上次使用的技能 | 无专属音 |

### 4.3 精英

**墨猿：**
- 入场：低吼+屏幕震动，BGM静默1秒
- 招式：捶地墨波（扇形AOE，可跳跃闪避）+ 冲锋抓取（QTE挣脱，成功免费涨墨爆发）
- 每损1/3血召唤一波墨浮+墨蠕
- 死亡：从头部碎裂→全身炸成墨瀑→墨能碎片如雨

**墨隼：**
- 入场：空中阴影逐渐扩大，地面墨圈变大
- 招式：俯冲（直线墨迹轨迹）+ 墨雨（升空洒墨滴，地面红圈预警）+ 翼斩（低空横扫扇形）
- 落地时不攻击（喘息窗口），鼓励疯狂输出
- 死亡：翅膀先碎→坠落→砸地→墨羽四散→全屏墨羽飘落5秒

### 4.4 Boss：墨脉古灵

**形象**：巨大半身人形从墨池升起，无下半身，墨脉根系连地面。空白面具，眼眶渗出墨泪。

**三阶段：**

| 阶段 | 血量 | 内容 |
|------|------|------|
| 根系 | 100%-70% | 古灵不动，四条墨脉根须横扫/穿刺，砍断全部进入下阶段 |
| 本体 | 70%-30% | 单掌拍地（扇形墨爆）、双手合十（全屏墨柱升起找缝隙）、墨泪滴落（随机墨池） |
| 崩解 | 30%-0% | 招式更快更密，攻击力下降，涨墨掉落翻倍——"最后一轮往死里砍" |

**击杀**：面具裂开→白光溢出→全身墨化崩解→墨雨洒落全屏→名字浮现→成就弹窗

### 4.5 节奏曲线

```
0'  安静开场，仅墨浮
2'  第一只墨蠕破土
4'  墨浮分裂↑，墨爆首次出现
5'  第一个墨蛹出现（不攻击但压迫感飙升）
7'  全种类小怪到齐，第一次满3段涨墨爆发
8'  爆发后3秒安静 → 墨猿低吼
10' 墨镜首次出现 + 墨缚配合
12' 墨蛭首次出现
15' 墨隼俯冲
16-19' 全小怪 + 双精英同时在场（最难时刻）
20' 清场 → 古灵升起
25' 必须结束
```

## 五、视觉设计

### 5.1 配色体系（7色限制）

| 色号 | 用途 |
|------|------|
| 墨黑 `#0a0a0f` | 背景基底、角色主体 |
| 纸白 `#e8e0d4` | 武器拖尾、爆发、文字 |
| 朱砂 `#c23b2a` | 暴击、受伤、致命提示、血量 |
| 苍青 `#3a7ca5` | 涨墨条、墨能碎片、灵体微光 |
| 暗灰 `#2a2830` | UI底色、地面纹理 |
| 暮紫 `#5c3d6e` | 精英/Boss点缀、稀有掉落 |
| 残金 `#b8935a` | 传说级掉落、终极质变、图鉴完成 |

### 5.2 视觉分层

```
UI层（最前）    → 涨墨条、血量、连击数、计时器
特效层          → 粒子、拖尾、墨花、伤害数字
角色 & 敌人层   → 剪影主体 + 手绘纹理叠加
地面层          → 墨骸残留、墨池、地面纹理
背景层（最后）  → 极简笔触暗示场景
```

### 5.3 三层背景

1. **宣纸纤维纹理**：极细微纸纤维，极慢漂移（0.1px/s），像纸在呼吸
2. **墨韵晕染**：随机墨色晕染，每局不同，15分钟内缓慢扩散变淡
3. **场景暗示笔触**：极简几笔暗示场景，视差偏移（玩家移动时笔触移动速度为10%）

### 5.4 光照系统（实时光照）

| 光源 | 强度 | 颜色 | 行为 |
|------|------|------|------|
| 主角墨核 | 弱→强 | 苍青 | 随涨墨段位渐变，3秒呼吸周期 |
| 敌人灵体微光 | 微弱 | 苍青 | 本身发光，死后熄灭 |
| 涨墨碎片 | 中 | 苍青+纸白 | 掉落物自发光 |
| 涨墨爆发 | 极强 | 纸白→苍青 | 瞬间最强，0.5秒衰减 |
| 朱砂警示 | 强 | 朱砂 | 暴击/濒死/精英出场 |

### 5.5 墨痕拖尾（书法笔触）

用 `Line2D` 实现书法线条：
- 起刀（入笔）→ 最粗最浓（藏锋）
- 行刀（行笔）→ 渐细渐淡（中锋）
- 收刀（出锋）→ 最细，带飞白（噪声纹理在末端随机衰减Alpha）
- 弯刀 → 外侧比内侧粗（笔锋偏侧）

### 5.6 墨花（击杀特效）

不是球形爆炸，而是**墨菊绽开**：

```
T=0.00s  敌人中心出现墨点
T=0.05s  8-12片弯曲墨线花瓣以不同速度向外伸展，有粗细变化，尖端带飞白
T=0.20s  花瓣到达最大半径
T=0.25s  花瓣碎裂 → 墨滴飘落
T=0.50s  墨滴落地留微小墨渍
```

| 击杀方式 | 墨花形态 |
|----------|----------|
| 普攻 | 小墨菊，5-6瓣，纸白 |
| 暴击 | 大墨菊，10-12瓣，纸白+朱砂描边 |
| 重击 | 墨牡丹，花瓣层叠，中央浓墨核心 |
| 连击50+ | 墨菊带苍青光晕，花瓣尖端发光 |
| 爆发清场 | 全屏墨花同时绽放又同时凋零 |

### 5.7 屏幕效果

| 效果 | 触发 | 方式 |
|------|------|------|
| 墨染暗角 | 涨墨2/3段 | 四角渐黑 |
| 命中停帧 | 暴击/重击 | 画面冻结2-4帧 |
| 屏幕震动 | 爆发/重击/墨猿砸地 | 幅度三级 |
| 全黑/全白闪 | 爆发/击杀Boss | 0.3秒反差 |
| 墨沸波纹 | 30+连击 | 边缘墨色波纹持续扩散 |

### 5.8 字体

| 用途 | 方案 |
|------|------|
| 伤害数字 | 繁体衬线体（Noto Serif TC），Bold，微斜 |
| 标题/质变名 | AI生成毛笔字贴图（仅十几个词，一小时搞定） |
| UI标签 | 细宋体，小字号，高字间距，淡纸白 |
| 连击数字 | 大字衬线体，残金色，宣纸纹理叠加 |
| Boss名字 | 手写笔触大字，全屏居中，苍青→纸白渐变 |

### 5.9 UI 布局

```
┌──────────────────────────────────────┐
│ [连击数: 87]              [计时 18:24] │
│                                        │
│              战斗区域                   │
│          (整个屏幕是画布)               │
│                                        │
│                                        │
│ [涨墨条 ▓▓▓▒▒▒▒▒▒▒▒▒]  [武器形态图标]  │
│ [血量  ▓▓▓▓▓▓▓▓░░░]    [共鸣状态图标]  │
└──────────────────────────────────────┘
```

原则：所有UI放四角不挡中心，无边框无按钮底色，元素"浮在墨上"，像碑帖拓印。

### 5.10 武器形态变化

| 状态 | 外观 |
|------|------|
| 默认墨刃 | 细长墨色弯刀剪影，墨痕拖尾 |
| 三连击（沥墨质变） | 刃分三叉，拖尾变三道细线 |
| 重击（凝墨质变） | 刃宽大厚重，拖尾短粗浓墨 |
| 涨墨满段 | 发苍青光，墨滴从刃尖渗出 |
| 墨沸（50连击+） | 燃白色火焰状墨焰 |

### 5.11 过渡动画

| 场景 | 做法 |
|------|------|
| 菜单→游戏 | 墨滴扩散，战斗画面从墨中浮现 |
| 升级选牌 | 画面微暗→三张牌从墨核飞出→悬停中央→墨迹晕染边缘 |
| 受击 | 四角墨染瞬间加深→0.2秒恢复 |
| 死亡 | 画面从边缘向中央被墨吞噬（1秒）→结算从墨中浮现 |
| 胜利 | Boss碎裂墨花→聚向中央→墨团晕开→结算界面 |
| 暂停 | 墨染暗角加重→时间缓慢冻结（0.3秒慢动作到停） |

## 六、音频设计

### 6.1 分层架构

```
音乐层（底层持续）→ 动态分层音乐，随战斗强度切换
环境音层           → 墨脉深处低频嗡鸣、墨滴回声
战斗音效层（密集）   → 挥刀、命中、击杀、涨墨、粒子、敌人
UI音效层（稀疏）    → 选牌、确认、升级、弹出
演出音效（关键时刻） → Boss登场、涨墨满段、质变选择、胜利/死亡
```

### 6.2 动态音乐系统

| 层 | 内容 | 触发 |
|----|------|------|
| 底层 | 氛围drone，长音低频嗡鸣 + 古琴泛音 | 始终 |
| 节奏层 | 鼓点/打击乐逐级叠加 | 敌人密度↑ |
| 高潮层 | 唢呐/筝扫弦/电子贝斯 | 涨墨满段、Boss战 |

### 6.6 技术要点

- 变调防疲劳：每次播放音高 ±10%、音量 ±5%、速度 ±8% 随机
- 空间音频：`AudioStreamPlayer2D` 定位，屏幕外敌人带低通滤波
- 优先级剔除：`AudioServer` 最大并发数管理，爆发 > 预警 > 小怪死亡
- 屏幕外威胁：墨染暗角+对应方向细墨丝纹路+左右声道区分

## 十二、品质自检清单

### 视觉
- □ 有没有任何东西是"突然出现"没有过渡的？
- □ 每个光源都能说清"这个光是哪来的"？
- □ 墨痕拖尾有没有粗细变化（飞白）？
- □ 伤害数字有没有互相遮挡？
- □ 暂停是"停滞"还是"凝固"？
- □ 有没有UI元素是标准矩形框？
- □ Boss出场有没有专属演出？
- □ 安静时刻的画面是不是也值得截图？
- □ 标题字是字体打的还是手写贴图？

### 音频
- □ 关掉音乐，光听音效能判断战局形势吗？
- □ 关掉音效，光听音乐情绪曲线对吗？
- □ 同一个音效连续播20次会觉得烦吗？
- □ 涨墨爆发那一下有没有"震"到？
- □ 屏幕外威胁闭眼能听出方向吗？
- □ 安静时刻是真的安静吗（无杂音/电流底噪）？
- □ UI音效和战斗音效抢戏吗？
- □ 死亡音效是"我想再来一局"还是"我要Alt+F4"？

### 玩法
- □ 每一刀命中都有反馈（停帧+音效+粒子+数字）吗？
- □ 25分钟内有没有超过2分钟的"单调期"？
- □ 三种Build分支玩起来像三款不同的游戏吗？
- □ 质变选择会让人犹豫吗？
- □ 第一次涨墨3段爆发有记忆点吗？
