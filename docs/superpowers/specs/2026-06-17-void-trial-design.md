# 🪐 虚空试炼 (Void Trial) — 设计文档

## 1. 项目定位

一个第一人称 3D 极简战斗游戏。玩家站在抽象虚空中的悬浮平台上，用魔法弹射击几何人形敌人，通过走位和闪避生存，逐步清空波次闯关。核心设计原则：**极简几何美术 + 精准爆头爽感 + 扎实战斗手感**。

- **引擎：** Godot 4.x（GDScript）
- **视角：** 第一人称
- **发布：** Windows / macOS / Linux 可执行文件
- **学习目标：** 3D 场景搭建、第一人称操控、碰撞检测、敌人 AI、粒子特效、UI 系统

## 2. 核心循环

```
进入平台 → 遭遇敌人（近战冲脸 + 远程弹幕）
         → 走位 + 射击 + 闪避
         → 清空当前波次所有敌人
         → 短暂喘息
         → 下一波次（敌人更多/更强）
         → 清空全部波次 → 过关 → 进入下一平台
```

### MVP 范围

| 维度 | 内容 |
|------|------|
| 场景 | 1 个抽象悬浮平台 + 几何掩体 + 装饰建筑 |
| 敌人 | 冲撞者（近战冲脸）+ 喷射者（远程弹幕） |
| 玩家 | WASD 移动、鼠标视角、左键射击、空格闪避 |
| 波次 | 每关 3 波，每波敌人数量和强度递增 |
| 关卡 | 第 1 关完全实现，第 2/3 关占位（"敬请期待"） |
| 美术 | 全几何体（球/柱/方块/棱锥/八面体）+ 粒子特效 + 发光材质 |
| 音效 | MVP 不做，后续统一加 |

## 3. 操控方式

| 操作 | 键位 | 说明 |
|------|------|------|
| 移动 | WASD | 前后左右 |
| 视角 | 鼠标移动 | 自由环顾，光标锁定到游戏窗口 |
| 射击 | 鼠标左键 | 发射魔法弹，冷却 0.3s |

## 5. 敌人设计

### 5.1 冲撞者（Charger）— 近战冲脸

人形几何体：球体头部 + 方块躯干 + 柱体四肢，红色发光材质，身高约 2 米。

| 属性 | 值 |
|------|-----|
| 生命值 | 30 |
| 移动速度 | 略慢于玩家步行 |
| 行为 | 检测玩家 → 径直冲来 → 身体短暂后仰（前摇）→ 冲刺 → 距离 < 1.5m 挥臂撞击 |
| 伤害 | 撞击一次 -15 HP |

| 命中部位 | 伤害 | 击杀所需发数 |
|----------|------|-------------|
| 🎯 头部（球体） | 20 | 2 发 |
| 💪 躯干（方块） | 10 | 3 发 |
| 🦵 四肢（柱体） | 6 | 5 发 |

### 5.2 喷射者（Spitter）— 远程弹幕

人形几何体：八面体头部 + 方块躯干 + 悬浮双腿，蓝色冷光材质，身高约 1.8 米，悬浮离地 0.5m。

| 属性 | 值 |
|------|-----|
| 生命值 | 20 |
| 移动速度 | 缓慢，环形移动 |
| 行为 | 保持 8-15m 距离，绕玩家环移 → 头部亮起蓄力 0.5s（前摇）→ 从掌心发射光弹 |
| 伤害 | 光弹命中 -10 HP |

| 命中部位 | 伤害 | 击杀所需发数 |
|----------|------|-------------|
| 🎯 头部（八面体） | 20 | 1 发秒杀 |
| 💪 躯干（方块） | 8 | 3 发 |
| 🦵 四肢（柱体） | 5 | 4 发（命中腿部减速 1s） |

## 6. 命中判定精度保障

### 6.1 碰撞体精确贴合

每个敌人挂载多个 Area3D 子节点，碰撞形状精确匹配几何体，**略小 2-3%** 确保"看起来打到了才算"。

```
Charger (CharacterBody3D)
├── HeadArea (Area3D)          ← 球体，紧包头部
├── BodyArea (Area3D)          ← 盒体，紧包躯干
├── LeftArmArea (Area3D)       ← 细长盒体
├── RightArmArea (Area3D)      ← 细长盒体
├── LeftLegArea (Area3D)       ← 细长盒体
└── RightLegArea (Area3D)      ← 细长盒体
```

### 6.2 连续碰撞检测（CCD）

子弹用 RigidBody3D + `continuous_cd = true`，Godot 自动处理高速穿透，防止子弹飞太快帧间穿模。

### 6.3 部位优先级

子弹同时碰到多个部位时（边界情况），按优先级取最高部位：
`HeadArea > BodyArea > ArmArea / LegArea`

### 6.4 调试可视化（开发阶段）

- F1 键切换显示所有碰撞体线框
- 命中点打出小红球停留 0.5s，肉眼确认判定位置
- 控制台打印命中部位和伤害值

## 7. 爆头爽感系统

### 第一层：命中瞬间反馈（每次爆头触发）

| 元素 | 爆头 | 身体（对比） |
|------|------|-------------|
| 准星 | 扩大 + 短暂变金色，额外扩散一圈金环 | 白色轻微扩大 |
| 伤害数字 | **金色大号 + "🎯"前缀** + 向上弹出更远 | 白色小号 |
| 粒子 | 命中点爆出一簇**金色火花碎片**，放射状飞溅 | 白色小光点 |
| 音效 | "叮"金属清脆声（后续加） | "噗"低沉声（后续加） |

### 第二层：击杀爆头特效（致命一击时额外触发）

| 元素 | 效果 |
|------|------|
| ⏱️ 极短时停 | 子弹命中瞬间 **0.05s 时间冻结**，然后恢复正常速度 |
| 💀 死亡动画 | 头部碎裂飞散 → 身体向后仰倒 → 碎片几何体扩散消散 |
| 🌟 屏幕反馈 | 屏幕边缘**金色脉冲一圈**，快速消散 |
| ✨ 弹道残留 | 爆头那一发弹道光轨多留 0.5s，金黄色更亮 |

### 第三层：爆头计数 & 评价

| 机制 | 说明 |
|------|------|
| 连杀爆头计数器 | 屏幕上方短暂显示 "🎯 爆头 x3"，连续爆头数字跳动 |
| 过关评价 | 结算时显示爆头率，如 "🎯 神射手 — 爆头率 42%" |
| 里程碑提示 | 累计 10/50/100 爆头时弹出成就提示（后续可做成就系统） |

### 第四层：连杀爆头叠加加成（后续版本）

| 叠加 | 效果 |
|------|------|
| 连续爆头 x3 | 下一次爆头伤害 +50%，弹道变金 |
| 连续爆头 x5 | 短暂无限弹药 + 弹道变烈焰色 |
| 连续爆头 x10 | 全场敌人短暂减速 2s |

> MVP 实现第一层 + 第二层 + 第三层计数器。第四层后续做。

### 10.4 游戏循环（每帧）

```
1. 读取输入 → 移动 / 旋转视角
2. 按左键 → 生成魔法弹
3. 按空格 → 执行闪避
4. 魔法弹飞行 → 碰撞检测 → 命中敌人 / 飞出边界销毁
5. 敌人 AI 更新 → 移动 / 攻击 / 发射弹幕
6. 敌人弹幕飞行 → 碰撞检测 → 命中玩家 → 扣血
7. WaveManager 检测波次全清 → 触发下一波或过关
8. 粒子衰减、伤害数字淡出
9. HUD 更新
```
