# QuoteWall · 格言墙 — 设计文档

## 1. 项目定位

一面可以浏览、筛选、收藏、投稿的格言墙。卡片随机散落排列，支持标签筛选。你和朋友共同丰富这座格言库。

## 2. 核心功能

### 基础体验

| 功能 | 描述 |
|------|------|
| 卡片墙 | 所有已审核格言以卡片形式散落展示，CSS Grid 自适应排列 |
| 随机顺序 | 每次加载页面时随机打乱卡片顺序，有偶遇感 |
| 标签筛选 | 点击标签徽章筛选该类别的格言 |
| 收藏 | 点 ❤️ 收藏到本地 localStorage |

### 投稿与审核

| 功能 | 描述 |
|------|------|
| 投稿表单 | 填写格言内容、作者、出处、选择标签，提交后默认隐藏 |
| 审核面板 | 管理员（和留言板同一个 admin 开关）可看到待审核列表 |
| 通过/拒绝 | 管理员点"通过"后格言公开可见；拒绝则删除 |

### 管理员

- F12 → Console → `localStorage.setItem("sb_admin","true")` → 刷新即可
- 每张卡片右上角出现审核按钮（待审核格言）或删除按钮（已通过格言）

## 3. 数据模型

```sql
CREATE TABLE quotes (
  id BIGSERIAL PRIMARY KEY,
  text TEXT NOT NULL,           -- 格言内容
  author TEXT,                  -- 作者
  source TEXT,                  -- 出处
  tags TEXT NOT NULL DEFAULT '[]',  -- JSON array: ["哲学","人生"]
  approved BOOLEAN DEFAULT false,   -- 审核状态
  device_id TEXT NOT NULL,      -- 投稿人设备 ID
  created_at TIMESTAMPTZ DEFAULT NOW()
);
```

> 和留言板共用同一个 Supabase 项目，新增一张 `quotes` 表。

## 4. 技术栈

| 层面 | 选择 |
|------|------|
| 前端 | 纯 HTML/CSS/JS，引用 Supabase JS SDK |
| 数据库 | Supabase (PostgreSQL) |
| 部署 | GitHub Pages，路径 `/quotes/index.html` |
| 管理 | localStorage admin 开关 |

## 7. 初始格言（预置 30 条）

你把主页那 20 条搬过来，再加上 10 条新的一起作为首批内容。先手动 INSERT 到 Supabase。
