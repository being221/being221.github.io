# 结构施工图 DXF 生成 — 设计文档

## 目标

从已完成 5400 计算书生成 6 张结构施工图 DXF 文件，天正可打开编辑打印。

## 技术栈

- Python 3 + ezdxf 1.4.3
- 标准字体：simhei.ttf / gbenor.shx（PROXY TTF 方法）
- 中国制图标准 GB/T 50001

## 图纸清单

### 1. 结构设计总说明 (A3 横, 420×297)
- 工程概况表（跨度/层高/面积）
- 材料表（C30/HRB400）
- 截面尺寸表
- 荷载取值表
- 规范依据表
- 图层：TITLE-说明, TABLE-总说明

### 2. 基础平面布置图 + 详图 (A2 横, 594×420)
- 左半：基础平面布置（轴线 A-D，柱网 3 列）
  - JC-1 边柱独基 (2.8×3.2, h=800)
  - JC-2 中柱联合基础
  - 轴线标注 5400/2400/5400
- 右半：JC-1 剖面 (1-1) + JC-2 剖面 (2-2)
  - 配筋标注 C14@150 双向/C12@200 顶面
- 数据来源：第11章 表11-1

### 3. 柱平面配筋图 (A2 横, 594×420)
- 柱网平面（2F-6F）+ 1F 单独
- KZ-A~D 平法标注 (16G101-1)
- 柱配筋表（楼层×柱配筋）
- 数据来源：第8章 表8-7~12

### 4. 梁平面配筋图 (A2 横, 594×420)
- 1F 平面 + 2F-6F 平面
- KL1/KL2 集中标注：b×h, 纵筋, 箍筋, 腰筋
- 梁端/跨中弯矩标注
- 数据来源：第8章 表8-4~6

### 5. 板平面配筋图 (A2 横, 594×420)
- 标准层板平面 A板(5.4×3.45) + B板(6.9×2.4)
- 板底/支座配筋 C8@200
- 弯矩标注
- 数据来源：第9章 表9-3~4

### 6. 楼梯详图 (A3 竖, 297×420)
- 平面图（梯段+平台+梯梁）
- 剖面图（踏步 167×280）
- 配筋表
- 数据来源：第10章

## 公共元素

- 标题栏：A2/A3 标准 180×56mm
- 图框：带会签/装订线
- 轴线圈 8mm 圆弧 + 文字
- 标注样式：ISO-25 改编
- 线型：轴线(DASHDOT)、轮廓(CONTINUOUS 0.35)、钢筋(CONTINUOUS 0.25)、细线(CONTINUOUS 0.18)
