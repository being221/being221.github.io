# DailyQuestion · 每日一题 — 设计文档

## 1. 项目定位

一个极简的每日思考题社区。每天一道开放式问题，用户匿名写下自己的回答。第二天可以看到其他人的回答。不用登录，不用注册，每天花两分钟想一个问题。

## 2. 核心功能

### 日常体验

| 功能 | 描述 |
|------|------|
| 今日问题 | 页面顶部大字显示当天问题 |
| 写回答 | 文本框输入，可匿名署名（或留空） |
| 查看回答 | 今天的回答按时间排列在下方 |
| 答案广场 | 所有历史问题 + 回答可翻阅 |

### 问题管理

| 功能 | 描述 |
|------|------|
| 问题库 | 预置 30 道问题（够用一个月） |
| 每日切换 | 每天 0 点自动切到下一道题 |
| 手动切换 | 管理员可手动更换当天问题 |
| 提交新题 | 访客可提交问题，管理员审核入库 |

### 互动

| 功能 | 描述 |
|------|------|
| ❤️ 点赞 | 给别人的回答点赞 |
| 回顾模式 | 按日期翻阅历史问题和回答 |

### 管理员

| 功能 | 描述 |
|------|------|
| 审核问题 | 管理面板可通过/拒绝用户提交的问题 |
| 手动选题 | 从问题库中手动选择今天的问题 |
| 删除回答 | 删除不当回答 |

## 3. 数据模型

```sql
-- 问题表
CREATE TABLE questions (
  id BIGSERIAL PRIMARY KEY,
  text TEXT NOT NULL,           -- 问题内容
  tags TEXT DEFAULT '[]',       -- JSON array: ["哲学","人生"]
  used BOOLEAN DEFAULT false,   -- 是否已被使用过
  approved BOOLEAN DEFAULT true, -- 审核状态
  device_id TEXT,               -- 提交人
  created_at TIMESTAMPTZ DEFAULT NOW()
);

-- 回答表
CREATE TABLE answers (
  id BIGSERIAL PRIMARY KEY,
  question_id BIGINT REFERENCES questions(id),
  text TEXT NOT NULL,            -- 回答内容
  author TEXT,                   -- 匿名署名（可选）
  device_id TEXT NOT NULL,       -- 回答人设备 ID
  likes INTEGER DEFAULT 0,       -- 点赞数
  created_at TIMESTAMPTZ DEFAULT NOW()
);

-- 每日问题表（记录哪天用了哪道题）
CREATE TABLE daily_question (
  id BIGSERIAL PRIMARY KEY,
  question_id BIGINT REFERENCES questions(id),
  date DATE NOT NULL UNIQUE
);
```

## 4. 技术栈

| 层面 | 选择 |
|------|------|
| 前端 | 纯 HTML/CSS/JS |
| 数据库 | Supabase (PostgreSQL) |
| 部署 | GitHub Pages，路径 `/daily/` |
| 定时任务 | 无——第一个访问当天页面的人触发问题分配 |
| 管理 | localStorage admin 开关 |

## 7. 预置问题（首批 30 道）

精选开放式问题，涵盖哲学、人生、记忆、想象、人际关系等——不涉及政治，不涉及隐私。

## 8. 验收标准

- ✅ 每天显示当天的问题
- ✅ 用户可匿名署名写回答
- ✅ 回答按时间排列，可点赞
- ✅ 历史页面可按日期翻阅
- ✅ 管理员可审核问题和删除回答
- ✅ 和格言墙、留言板共用一个 Supabase 项目
